Failed to check session lock minecraft server

The world folder is already in use — FATAL

What this actually means

Another process already holds this world. Either the server is genuinely still running, or a previous run did not shut down cleanly and left the session.lock held.

How to fix it

Make sure no other copy of the server is running -- check Task Manager for a java process, or `ps aux | grep java`. Stop it properly with the `stop` command, never by killing the window, or the lock survives. NOTE: if you are boot-testing a server while someone is playing on it, THIS is the error you get, and it tests nothing. Stop the live server first or test against a copy of the world.

What it looks like in your log

Search your crash report or latest.log for any of these:

Failed to check session lock
The directory  ...  is already being used
MinecraftException: Failed to check session lock
world is already in use
