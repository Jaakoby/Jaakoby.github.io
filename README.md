# jaakoby.github.io

Source for <https://jaakoby.github.io/> — command-line tools for people who run
modded Minecraft servers.

- **Forge Server Doctor** — reads a crash report and names the mod that killed
  your server. [Free edition](https://github.com/Jaakoby/forge-server-doctor).
- **Pack Doctor** — finds the modpack IDs that silently do nothing.
